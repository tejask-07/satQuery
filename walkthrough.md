### C. Diagnostic Error Analysis Findings

Primary Failure Mode: **`MIXED_PIXEL`** (845 pixels, **95.26%**)
- `MIXED_PIXEL`: 845 pixels (95.26%) — Boundary interface pixels between land-cover classes where WorldCover v100 and v200 algorithms shifted classification categories.
- `WATER_EPHEMERAL_CHANGE`: 19 pixels (2.14%) — Danube canal edge pixels.
- `CONFLICTING_INDICES`: 15 pixels (1.69%) — Minor contradictory index evidence.
- `INSUFFICIENT_TEMPORAL_EVIDENCE`: 8 pixels (0.90%) — Transient single-pair differences.

**Scientific Takeaway**:
WorldCover 2020 (v100) and 2021 (v200) used differing classification models, causing significant boundary shifts between classes across annual products, while Sentinel-2 physical spectral reflectances remained relatively stable. Rather than tuning thresholds to fit this single example, the pipeline was left unperturbed in strict adherence to scientific safeguards.
